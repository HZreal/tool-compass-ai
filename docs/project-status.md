# AI Scenery：产品总览与实施状态

> 最后核对：2026-09-01。本文是继续开发时的总入口；产品需求见 `superpowers/specs/`，可执行任务见 `superpowers/plans/`。

## 1. 产品目标

AI Scenery 是面向中文用户的 AI 工具发现平台：覆盖国内外成熟、广泛使用且值得推荐的产品。它的核心不是堆砌收录量，而是让用户在 30 秒内按真实工作任务找到合适工具、理解适用场景，并进入官网试用。

首批服务内容创作者、知识工作者和轻度 AI 使用者；开发者工具保留入口，但不应压过日常工作任务。

## 2. MVP 范围与验收口径

### 必须交付

1. 首页：搜索、精选、8 个分类、6 个任务场景、投稿入口。
2. 目录与搜索：发布工具可按关键词、分类、场景、地区、平台、定价筛选；筛选 URL 可分享；每页 18 条。
3. 工具详情：用途、标签、定价、核验日期、编辑说明、平台/语言、相似工具及匿名官网外跳统计。
4. 收录与纠错：匿名推荐/纠错、服务端 HTTPS 校验、蜜罐、待审核队列。
5. 单管理员后台：ChatGPT 登录后的精确 user ID allowlist；工具草稿/发布/归档、分类/场景/标签、精选排序、投稿审核与转草稿、审计记录。
6. 运行质量：360px 可用、键盘可操作、严格 TypeScript、测试通过、运维手册、D1 备份恢复和私有 Sites 发布验收。

### 明确不做

用户账户、跨设备收藏、评论社区、排行榜、自动抓取/评测、实时资讯、付费订阅、广告交易、开放 API、R2 上传和独立 Go/Gin 服务。

## 3. 技术决策（已确认）

| 层 | 选择 |
| --- | --- |
| 应用 | React + TypeScript + Vite + VINext |
| 托管 | Sites / Cloudflare Workers |
| 数据 | Cloudflare D1 + Drizzle migrations |
| 搜索 | D1 FTS5 trigram |
| 管理认证 | ChatGPT 身份头 + 服务端 `ADMIN_USER_ID` 精确匹配 |
| 测试 | Node test/Vitest 风格路由测试 + Playwright |

`D1` 是所有产品数据的唯一事实来源；公开读取只允许 `published` 工具；工具外链统一经过 `/go/:slug`，不保存 IP、账号或查询参数。

## 4. 当前实现状态

### 已完成并验证

- Sites VINext 应用、D1 绑定和根目录版本化迁移。
- 公开路由：首页 `/`、目录 `/discover`、搜索 `/search`、场景 `/scene/:slug`、详情 `/tool/:slug`、投稿 `/submit`、外跳 `/go/:slug`。
- 管理端：`/admin`、`/admin/tools`、`/admin/submissions`；本地预览的受控登录回退只在 localhost 有效，线上仍由 Sites 的 ChatGPT 登录承接。
- 公开记录只读取 `published`；投稿校验、蜜罐、匿名外跳事件、审核审计和并发审核保护已经实现。
- 工具数据新增别名、地区、Logo URL、精选排序；FTS 包含别名与标签文本。
- 种子定义已调整为原始 PRD 的中文 8 分类、6 场景和 80 条工具；自动化 D1 种子测试覆盖该契约。
- 目录服务端已支持分类、场景、关键词、精选、地区、平台、定价组合筛选、总数和 18 条分页；目录页 URL 同步 `region`、`platform`、`pricing`、`page`。
- 最近一次全量验证：`npm test` 41/41 通过，生产构建通过。

### 已完成但需同步本地预览数据

本地 `.wrangler/state` 已应用最新 schema migration，但仍保存早期英文分类/场景的种子内容。继续开发前应使用可重复的本地 seed 命令将其重导为当前 `db/seed.ts`，并检查首页、目录、场景页显示中文 IA。
