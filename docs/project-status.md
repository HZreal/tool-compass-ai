## 产品目标与固定范围

面向中文用户，覆盖国内外成熟、有价值的 AI 工具，按任务发现、理解用途并访问官网。保持独立编辑部视觉；不设置国内产品比例。单管理员，D1 是唯一权威数据源，只有 published 工具对外展示。

固定 8 分类：聊天与问答、写作与翻译、图像与设计、视频与音频、办公与效率、编程与开发、智能体与自动化、学习与研究。
固定 6 场景：写文章、做 PPT、生成图片、制作视频、提升办公效率、辅助编程。

技术路线保持 React + TypeScript + VINext/Vite + Sites/Cloudflare Worker + D1 + Drizzle migrations + FTS5。Go/Gin 是早期已被替代的选择，不再作为当前实现目标。

- 数据通过鉴权 POST /api/admin/catalog-import 导入；版本标记保证仅一次。管理员已经编辑的记录保留，不覆盖其资料。新结构的迁移只建 schema，绝不重置线上数据库。
